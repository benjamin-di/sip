Retain buffered final responses (#923). The release's sipResponse still returns
an incomplete transaction when Done wins over a queued final response. The
adaptation preserves the new cancellation-reason result and its downstream events.
Remove after an official release passes buffered 200/401/403/407 and incomplete
transaction regressions.

Retain explicit RTP, audio and combined DTMF modes (#943), with complete receiver
tests for ordered digits, end repeats and decoded G.711 frequency pairs. Preserve
the release's manual RTP timestamp stream, input validation and audio-drop switch.
Audio-only mode stays audible without telephone-event negotiation or an event
clock; event-only mode must report missing negotiation. The canonical release's
Media SDK 756e3cfaa8dd replaces the old 0de6c2e55d42 pin without a downgrade.
Remove after a release exposes the modes and passes their receiver regressions.

Retain configurable mixer input buffering (#608 / #727). The release's shared
call manager owns the room factory, so configuration is applied there while test
and caller overrides remain supported. The default stays at five frames.
Fake-clock starvation tests cover larger buffers retaining bursty audio.
Remove when a release exposes the option and passes the starvation tests.

Generic public CI and immutable image publishing support the remaining patches.
The inherited Docker Hub publisher stays disabled. No application configuration,
prompts, credentials, carrier settings or call data are carried.
